## Part B 阈值扫描（rerank 在场，排序=两路 RRF 融合序（生产，BM25 只扩池），闸门作用于 rerank 绝对分；基线行=rerank OFF 余弦闸 0.40）

每题检索只跑一次，各档闸门/各融合方案离线复算（与生产 rag.retrieve/main.py 逻辑逐行一致，含指代重试）。

指标定义：
- 引用覆盖率 = 有标准答案的题中，至少 1 条 grade≥2 引用被放行的比例
- 无引用比例 = 全部 100 题中出 0 条引用的比例（OOV 零引用是正确行为，14 题全部拦下时下限 14%）
- Precision = 放行块中 grade≥2 的比例；无关引用率 = 放行块中 grade0 的比例
- Recall = 放行的 grade≥2 块 / 闸前（该方案融合序）Top3 中的 grade≥2 块（闸门对排序结果的破坏度）
- top1正确率 = 有答案题中 top1 引用 grade≥2 的比例（最终答案质量代理——真实答案质量需 LLM 评审，另计）
