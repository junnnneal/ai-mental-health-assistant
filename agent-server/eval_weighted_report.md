## 结论

1. 全表 NDCG@3 最优：**生产 并集池 RRF(cos,rr)【基线】**（0.863）；生产基线 0.863。
2. 教科书族/两段式族 最优：**两段式 w_bm=1 + RRF(cos,rr)定序**（0.858），相对生产基线 -0.004。
3. 合并处权重扫描（教科书族）：最优 教科书 合并RRF w_bm=0.5（NDCG 0.812）；w_bm=1 文档原版 0.807；w_bm=0 余弦选池 0.812。
4. 生产架构下给 BM25 第三票（γ 扫描）：最优 连续票权 γ=0.25 并集三路加权（NDCG 0.848）vs γ=0 即生产基线 0.863——任何票权都不如不给。
5. 闸后（Part B）：top1 正确率 生产 0.882 vs 教科书族最优 0.859；无关引用率 0.056 vs 0.097。
